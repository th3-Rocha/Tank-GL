# Fader

Controle horizontal para níveis em dB e porcentagens que pedem leitura linear: IR LV, volume da pré-escuta.

- Props: `label`, `value`/`onChange` ou `defaultValue`, `min`, `max`, `step`, `unit`, `format`, `width`, `resetValue`, `disabled`.
- Clique na trilha para pular, arraste, setas para ajustar, duplo clique para voltar ao padrão.
- Parâmetros do pedal (GAIN, MIX…) são sempre `Knob`, não fader.
