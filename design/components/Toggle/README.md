# Toggle

O interruptor do editor oficial: âmbar com polegar branco quando ligado, cinza-claro quando desligado.

- Props: `label`, `checked`/`onChange` ou `defaultChecked`, `size` (`sm` em cabeçalhos de bloco), `hideLabel` (mantém o rótulo só para leitores de tela), `showState` (mostra ON/OFF ao lado), `disabled`.
- Liga coisas que agem na hora: Bypass, Loopback, ligar um efeito. Para escolher entre opções, use `SegmentedControl`.
