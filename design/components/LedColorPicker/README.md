# LedColorPicker

Escolhe a cor do LED de um preset entre as oito cores `led-*`.

- Props: `value`/`onChange` ou `defaultValue`, `colors` (lista de `{ value, label }`), `showName`, `label`.
- Cada amostra tem nome no `title` e no `aria-label`; a escolhida ganha anel branco e brilho da própria cor.
- As cores exatas que a Tank-G aceita ainda serão confirmadas na captura.
