# Tag

Rótulo curto de estado ou atributo: formato da IR, slot, "Modificado", tags de filtro.

- Props: `tone` (`neutral` · `amber` · `ok` · `warn` · `danger`), `size` (`sm` em linhas de tabela), `icon`, `count`, `onClick` + `selected` (vira filtro clicável), `onRemove`.
- Estados levam ícone e palavra juntos: `ok` + check "Salvo no pedal", `warn` + alerta "Modificado".
- No máximo três tags por linha de tabela.
