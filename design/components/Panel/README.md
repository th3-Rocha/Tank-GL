# Panel

Cartão grafite com título, ícone âmbar e ações, como os cartões IR e AM2Data do editor oficial.

- Props: `title`, `icon`, `meta` (texto mono à direita do título), `actions`, `flush` (sem padding, para tabelas), `sunken`, `children`.
- Use para agrupar uma tarefa (IR do preset, biblioteca, backup). Para um efeito com knobs, use `EffectBlock`.
