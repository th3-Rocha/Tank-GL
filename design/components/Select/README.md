# Select

Lista suspensa preta como o seletor de slot do editor oficial. Para escolher slot (1–8), preset, formato.

- Props: `label`, `hideLabel`, `options` (strings ou `{ value, label }`), `value`/`onChange` ou `defaultValue`, `size` (`sm` · `md`), `width`, `disabled`.
- Usa o `<select>` nativo, então teclado e leitores de tela funcionam de graça.
- Com mais de ~15 itens que o usuário precisa achar por nome, use a busca em vez de um select.
